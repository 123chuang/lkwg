# 键鼠信号发送器

一个本地桌面键鼠信号工具，支持：

- 循环发送键盘空格信号
- 循环发送鼠标左键信号
- 设置左键信号发送时间间隔，并在最小/最大区间内随机
- 设置左键信号持续时长，并在最短/最长区间内随机
- 设置空格按下持续时间、运行时长和启动前延迟
- 启动、暂停、停止
- 全局热键：`F8` 启动/暂停，`F9` 停止

Windows 上发送空格和鼠标左键使用系统 `SendInput` 接口，不做截图、不识别目标、不移动鼠标、不锁定目标。信号会发送到当前获得焦点的窗口，鼠标左键信号作用在当前鼠标位置。

## Windows 运行环境

推荐在 Windows 上安装 Python 3.11 或 3.12，并在安装时勾选 “Add Python to PATH”。

### 方式一：直接运行源码

把整个目录复制到 Windows 后，可以直接双击：

```bat
run_windows.bat
```

也可以手动运行：

```bat
py -3 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python auto_clicker.py
```

如果目标程序以管理员身份运行，这个工具也需要以管理员身份运行，否则 Windows 可能会阻止输入信号。

### 方式二：打包成 exe

在一台已经安装 Python 的 Windows 电脑上执行：

```bat
build_windows.bat
```

打包完成后，可执行文件在：

```text
dist\KeyMouseSignalSender.exe
```

把这个 exe 复制到没有 Python 环境的 Windows 电脑上即可运行。第一次启动时，杀毒软件可能会扫描较久；这是单文件 PyInstaller 程序的常见现象。

注意：建议在 Windows 上构建 Windows 版 exe。Linux 上直接运行 PyInstaller 通常只能生成 Linux 可执行文件，不能直接生成 Windows exe。

## 使用流程

1. 选择是否发送“键盘空格”和“鼠标左键”。
2. 设置运行时长，`0` 表示不限时。
3. 设置左键信号间隔最小/最大值，例如 `0.8` 到 `1.8` 秒。
4. 设置左键持续最短/最长时间，例如 `0.04` 到 `0.12` 秒。
5. 如需启动后切换到目标窗口，保持“启动后最小化窗口”开启，并把“启动前延迟”设置为 2 到 5 秒。
6. 点击“启动”，需要暂停时点击“暂停/继续”或按 `F8`。

## 停止

- 按 `F9` 立即停止。
- 点击窗口里的“停止”按钮。

## 注意事项

- 信号发送到当前获得焦点的窗口，不会后台指定窗口。
- 鼠标左键信号不会移动鼠标，作用位置就是当前鼠标所在位置。
- 某些游戏或软件可能拦截系统输入信号，或要求工具以管理员身份运行。
- Linux 上仅作为兼容开发模式运行，使用 `pynput` 发送输入。
